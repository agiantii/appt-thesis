\begin{chineseabstract}
	{智能幻灯片协作平台；实时协作；Yjs；Slidev；权限管理；AI辅助}\setlength{\parskip}{0pt}\linespread{0.95}\selectfont 传统幻灯片工具在团队协作、版本控制和智能辅助方面存在局限。本研究设计并实现了智能幻灯片协作平台，该平台整合实时协作、权限管理、AI辅助和简化版本控制，为技术团队和教育工作者提供高效的幻灯片制作与协作解决方案。

平台采用React + TypeScript + Vite构建前端，集成CodeMirror编辑器和Yjs协作库；后端采用NestJS框架，提供RESTful API和WebSocket协作服务。系统实现实时协作编辑，支持多用户同时编辑和实时光标追踪；设计基于RBAC的四级权限管理系统，实现细粒度文档访问控制；集成AI辅助功能，支持大语言模型的幻灯片内容生成和语法适配；构建简化版本控制系统，提供版本历史查看、差异对比和回滚功能。

本平台通过Yjs CRDT算法实现无冲突的实时协作编辑，降低非技术用户的使用门槛。平台表现出良好的稳定性和用户体验，提高团队协作效率，降低技术门槛，增强内容创作能力。

\end{chineseabstract}

\begin{englishabstract}
		{Intelligent Slideshow Collaboration Platform; Real-time Collaboration; Yjs; Slidev; Permission Management; AI Assistance}\setlength{\parskip}{0pt}Traditional slideshow tools have limitations in team collaboration, version control, and intelligent assistance. This research designs and implements an intelligent slideshow collaboration platform, integrating real-time collaboration, permission management, AI-assisted features, and simplified version control, providing efficient slideshow creation and collaboration solutions for technical teams and educators.

The platform adopts React + TypeScrip t + Vite for front-end development, integrating CodeMirror editor and Yjs collaboration library; the back-end uses NestJS framework to provide RESTful API and WebSocket collaboration services. The system implements real-time collaborative editing, supporting multi-user simultaneous editing and real-time cursor tracking; designs an RBAC-based four-level permission management system for fine-grained document access control; integrates AI-assisted features supporting large language model-based slideshow content generation and syntax adaptation; constructs a simplified version control system providing version history viewing, difference comparison, and rollback.

The platform implements conflict-free real-time collaborative editing through Yjs CRDT algorithms, lowering the barrier for non-technical users. The platform demonstrates good stability and user experience, improving team collaboration efficiency, lowering technical barriers, and enhancing content creation capabilities.

\end{englishabstract}

\begin{englishabstract}
	{Intelligent Slideshow Collaboration Platform; Real-time Collaboration; Yjs; Slidev; Permission Management}\setlength{\parskip}{0pt}
% Traditional slideshow tools have certain limitations in team collaboration, version control, and AI intelligent assistance.
The author designs and implements an intelligent slideshow collaboration platform that supports real-time collaboration, permission management, AI assistance, and simplified version control.
It helps presenters conveniently create slides using Markdown syntax adapted to Slidev, allowing them to focus solely on content creation rather than formatting.
Meanwhile, rich plugins and themes are available to achieve various interesting animation effects and visual presentations.

The platform adopts React for the frontend and NestJS for the backend, utilizing the Yjs CRDT algorithm to achieve conflict-free real-time collaborative editing, supporting multi-user collaborative editing and real-time cursor tracking.
An appropriate RBAC model is designed for permission management, without being overly complex or too simplistic.
A simplified version control system is built, providing version history viewing, difference comparison, and rollback functionality.
\end{englishabstract}

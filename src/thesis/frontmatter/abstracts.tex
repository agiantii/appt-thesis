\begin{chineseabstract}
	{智能幻灯片协作平台；实时协作；Yjs；Slidev}
		幻灯片是表达演讲者想法和呈现演讲内容的重要工具，
		而常见的幻灯片工具需要用户花费较多的精力在布局排版、样式调整上，
		而非内容创作。
		为解决以上问题，作者基于Slidev设计并开发了一个智能幻灯片协作平台，
		支持实时协作、权限管理、AI（人工智能）辅助和版本管理等功能，
		能够帮助演讲者很方便地使用适配于Slidev的Markdown语法来创作幻灯片，
		只需要关注内容创作而非排版、样式。
		同时还可以使用丰富的插件和主题实现许多有趣的动画效果和视觉呈现。	
		
		平台前端选用React，后端采用NestJS，
		使用MySQL来存储相关数据，
		通过Yjs的CRDT算法实现无冲突的实时协作编辑，
		支持多用户协同编辑和实时光标追踪，
		并通过NestJS提供的Guards来实现对编辑、查阅、评论等权限的管理，
		选择Qwen-Plus来辅助用户创作幻灯片，
		以快照存储的的方式实现版本管理，提供版本历史查看、差异对比和回滚功能。
		

\end{chineseabstract}

\begin{englishabstract}
{Intelligent Slide Collaboration Platform; Real-time Collaboration; Yjs; Slidev}
		Slides are important tools for conveying speakers' ideas and presenting speech content.
		However, common slide tools require users to spend a lot of effort on layout and style adjustments
		rather than content creation.
		To solve the above problems, the author designed and developed an intelligent slide collaboration platform based on Slidev,
		which supports functions such as real-time collaboration, permission management, AI(Artificial Intelligence) assistance, and version management.
		It can help speakers conveniently create slides using Slidev-compatible Markdown syntax,
		allowing them to focus only on content creation instead of layout and styling.
		At the same time, a wealth of plugins and themes can be used to achieve many interesting animation effects and visual presentations.
		
		The platform adopts React for the frontend and NestJS for the backend,
		and uses MySQL to store relevant data.
		It achieves conflict-free real-time collaborative editing through Yjs's CRDT algorithm,
		supporting multi-user collaborative editing and real-time cursor tracking.
		Permission management for operations such as editing, viewing, and commenting is implemented via Guards provided by NestJS.
		Qwen-Plus is selected to assist users in creating slides,
		and version management is realized through snapshot storage, providing functions including version history viewing, difference comparison, and rollback.
\end{englishabstract}

\begin{chineseabstract}
	{智能幻灯片协作平台；实时协作；Yjs；Slidev；权限管理}
		幻灯片是表达演讲者想法的重要工具，而常见的幻灯片工具需要用户花费较多的精力在布局排版上，
		而非内容创作。
		而且版本管理较为困难，难以方便地看出各个版本的修改区别，同时协作时也会产生许多冗余的版本。
		为解决以上问题，作者基于Slidev设计并实现了一个智能幻灯片协作平台，支持实时协作、权限管理、AI辅助和简单的版本控制，
		能够帮助演讲者很方便地使用适配于Slidev的Markdown语法来制作幻灯片，只需要关注内容创作而非排版。
		同时还可以使用丰富的插件和主题实现许多有趣的动画效果和视觉呈现。	
		
		平台前端选用React，后端使用NestJS，通过Yjs的CRDT算法实现无冲突的实时协作编辑，支持多用户协同编辑和实时光标追踪；
		设计合适的RBAC模型来实现编辑、查阅、评论等权限管理；支持简单的版本控制，提供版本历史查看、差异对比和回滚功能。
		

\end{chineseabstract}

\begin{englishabstract}
{Intelligent Slide Collaboration Platform; real-time collaboration; Yjs; Slidev; permission management}
		Slides are important tools for conveying a speaker's ideas. However, common slide tools require users to spend considerable effort on layout and formatting rather than on content creation. Moreover, version management is difficult, making it hard to easily see the differences between versions, and collaboration often generates many redundant versions. To address these issues, the author designed and implemented an intelligent slide collaboration platform based on Slidev, which supports real-time collaboration, permission management, AI assistance, and simple version control. It allows speakers to conveniently create slides using Markdown syntax adapted for Slidev, enabling them to focus on content creation rather than formatting. At the same time, rich plugins and themes can be used to achieve many interesting animation effects and visual presentations.
		
		The frontend of the platform is built with React, while the backend uses NestJS. Conflict-free real-time collaborative editing is implemented through Yjs’s CRDT algorithm, supporting multi-user collaborative editing and real-time cursor tracking. An appropriate RBAC model is designed to manage permissions such as editing, viewing, and commenting. The platform also supports simple version control, offering version history viewing, diff comparison, and rollback functionality.

\end{englishabstract}

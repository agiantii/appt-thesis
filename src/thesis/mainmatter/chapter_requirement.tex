\section{系统功能性需求}
为了实现一个功能完善、简单易上手的智能幻灯片协作平台，帮助用户专注于高效的内容创作，
主要包括登录平台、管理幻灯片、评论幻灯片、管理协作者权限、创作幻灯片、管理代码片段等功能需求，
由于幻灯片是根据适配Markdown语法的幻灯片文档渲染出来的，
对幻灯片的编辑，本质就是对幻灯片文档的编辑，
所以在后续针对幻灯片创作的描述，多以幻灯片文档来描述。

\begin{enumerate}
    \item 登录平台：已经登录的用户需要直接跳转到“工作台”界面，
    该界面需要显示常用的功能项，而未登录的用户需要输入验证码、用户名或邮箱、密码，
    系统需要校验验证码是否正确，而后对用户名或邮箱、密码的格式以及正确性进行校验。
    \item 管理幻灯片：系统参考语雀对文档的管理思路来管理幻灯片，首先在“工作台”界面会显示
    最近编辑、共享的幻灯片以及用户个人的幻灯片空间，用户能够添加、删除、重命名幻灯片空间，
    而幻灯片空间中支持列表结构或树形结构显示幻灯片，
    列表结构显示幻灯片的预览图片和幻灯片名称，而树形结构只显示幻灯片名称。
    用户可以删除、添加、重命名幻灯片，也可以通过拖拽来调整空间内的幻灯片层级结构，
    删除幻灯片时，也会将其子节点的幻灯片都一并删除。
    \item 评论幻灯片：用户在浏览幻灯片时，需要能够评论幻灯片，这可以为演讲者提供一定的反馈，
    从而可以进一步提高幻灯片的品质，用户可以发表、删除评论，只有评论者才能删除评论，且删除时会一并删除子评论。
    \item 管理协作者权限：对于协作者的权限进行管理，同时需要能够通过用户名来搜索用户，
    并邀请需要共创的协作者，同时也能删除协作者、更改协作者的权限。
    \item 创作幻灯片：作为智能幻灯片协作平台，该功能是最为重要的。
    首先，需要配有功能齐全的编辑器，支持语法高亮、代码片段插入、代码提示、快捷键使用等。
    对于快捷键，用户可以在编辑器中使用Ctrl+V上传图片/视频，并以图片/视频链接插入编辑器中，
    也可以使用Ctrl+B来呼出/关闭左侧编辑器工具栏，使用Ctrl+Alt+B来呼出/关闭右侧预览预览窗口，
    预览窗口中需要能够显示Slidev渲染的幻灯片，同时根据Slidev的语法计算出幻灯片大纲，点击对应大纲，
    预览窗口和编辑器窗口都需要跳转到对应的幻灯片位置。
    作为幻灯片协作平台，协同编辑也是必不可少的，需要能够显示其他协作者正在编辑的区域和光标位置。
    考虑到当用户在编辑幻灯片文档时，经常会出现一些错误，需要进行撤销，
	同时有时需要撤销回到较为久远的文档版本。为了降低用户使用的门槛，
	本平台需要实现版本管理功能，
    支持版本历史查看、内容差异对比和一键回滚操作。
    为提高幻灯片创作效率，平台支持实现幻灯片文档大纲生成、内联编辑等功能，
    其中，文档大纲生成允许用户上传文本文件作为内容生成的参考文档。
    而内联编辑可由快捷键Ctrl+I触发，支持语法修复、内容润色、布局调整、文生图等功能。
    \item 管理代码片段：为用户在创作幻灯片时使用自定的代码片段，
    需要在个人设置中管理用户的代码片段，代码片段包括代码片段名称和代码片段内容，
    且代码片段名称作为编辑器前缀匹配的依据，不能重复。
\end{enumerate}

\section{系统非功能性需求}

% 作为一个幻灯片协作平台，
% 在常规网络条件下，页面加载与常规请求的响应时间应该在可接受的范围内，
% 并支持一定规模的并发编辑，不会出现内容不一致、过分卡顿的情况。

为了让用户能快速上手和高效地创作幻灯片，
幻灯片创作界面的应该避免过分复杂和冗余的元素，
主要呈现幻灯片文档的编辑器、左侧工具栏以及右侧的幻灯片预览窗口，
% 且可以调节各个窗口的大小，
其他功能窗口通过点击按钮或是快捷键呼出/关闭，
且按钮的功能图标要直观、清晰，让用户能够快速就能找到所需要的功能，
同时设计常用的快捷键使用方式让这些功能使用更加方便、简化操作的流程。
对于版本对比，需要以一种直观的方式可视化不同版本的差异，
让用户能够清晰地看到不同版本之间的差异。
% 同时针对用户对主题的偏好，本平台支持暗色/亮色主题的切换，以黑白配色为主。

对于所有核心API请求，都要通过JWT认证以及权限校验，
且都要对请求参数进行格式校验。
同时在用户注册和登录都用需要对用户信息使用bcrypt进行加密，
而且需要将密码加密存储到数据库。
在Websocket连接前也需要进行JWT认证和权限校验，
确保非协作者不能参与幻灯片文档协作以及没有编辑权限的用户不能编辑幻灯片文档。

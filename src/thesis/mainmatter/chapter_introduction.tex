	\section{研究背景及意义}\label{sec:background}

	
	幻灯片是表达演讲者想法和便于沟通的重要工具，
	常见的幻灯片工具如Microsoft PowerPoint采用“所见即所得”的编辑方式，
	虽然这种方式在许多地方符合直觉且容易上手，
	但在排版布局、跨平台的兼容性、代码展示等方面仍然存在许多不便，
	需要用户花费较多精力在布局排版、调整样式上，而非内容创作。

	基于Web的轻量化幻灯片工具逐渐出现在人们的视野，
	% 如Reveal.js、Marp、Slidev等工具支持用Markdown语法编写幻灯片内容，
	% 还可以结合现代Web栈实现许多有趣且丰富的交互效果。
	其中，Slidev作为一个基于Web的幻灯片渲染引擎，不仅支持用Vue编写组件，而且支持丰富的自定义插件和主题，
	可以通过Slidev的主题等配置完成大部分布局排版和样式的设置。让用户以Markdown的形式专注于编写幻灯片的内容，
	并制作出具有交互式演示功能的、高度可自定义的幻灯片\cite{slidevteam2026slidedoc}。
	% Markdown作为一种轻量级标记语言，因其简洁性和易读性在文档编写中广泛应用。
	% 但是Slidev缺乏一个在线协作的平台，无法支持多人同时编辑同一份幻灯片，
	% 尽管可以使用Git这类版本管理工具进行离线协作，但对于幻灯片制作这类场景，有时更需要团队讨论和实时协作。
	% 此外，每个Slidev构建的幻灯片都是静态网页，用户没有可以系统管理自己幻灯片的平台。

Slidev构建出的幻灯片本质是一个网页，
通过其URL（Uniform Resource Locator，统一资源定位符）就可以分享最新的幻灯片给其他用户，
而制作者需要将构建好的JavaScript、CSS等资源部署到服务器上，
想要修改幻灯片时，制作者必须要在有Slidev相关环境的电脑上，
修改后又需要将构建好的网页部署到服务器，
此时，一个云端编辑平台显得尤为重要了。
其次，对于一些授课场景，一门课程往往是分为很多章节的，
如数据结构课程中需要分为图论、排序算法等章节，
而排序算法章节又可能分为插入排序、归并排序等子章节，
需要管理这些幻灯片的层级结构。
再者，在利用Slidev制作幻灯片时，虽然可以通过Git等版本管理工具进行“离线协作”，
但是有时候需要进行审阅批注和实时团队协作，这可以让幻灯片制作更加高效。
% 利用Slidev制作幻灯片，
% 本质就是以一套封装好的主题、插件编写Markdown的来制作网页，
% 其一些语法对于用户来说，仍然具有一定的门槛，但是AI

	综合以上背景，作者将设计与开发一个基于Slidev的智能幻灯片协作平台，
	该平台将支持实时协作、权限管理、AI辅助功能和版本管理等功能，
	可以让多个用户实时协同编辑同一个幻灯片，提高团队工作效率并减少沟通成本，
	而且版本管理功能可以让用户很方便地查看历史版本、对比版本差异以及回滚版本。
	利用加入了Slidev相关知识库的AI，
	还可以帮助用户快速生成幻灯片大纲并优化内容，让幻灯片创作更高效、更优质。
	% 该平台可以让用户以Markdown的形式专注于编写幻灯片的内容，而非布局排版，
	% 并支持树形结构管理幻灯片、实时协作等功能，
	% 同时还可以利用AI辅助让幻灯片制作更加高效、便捷。

	\section{研究现状}\label{sec:history}

	在幻灯片制作进入计算机时代后，
	PowerPoint和Keynote逐渐成为大众的主流选择，
	% 演讲者常常选择PowerPoint和Keynote来制作幻灯片，
	演讲者只需要通过拖拽基本组件、设置样式等直观的方式就可以制作幻灯片。
	% 制作出一份基本幻灯片，
	但是，一方面，
	这种方式往往需要用户将幻灯片文件下载到设备上，	
	还需要该设备安装了对应的软件才能放映。
	% 而且可能会因软件兼容性等问题出现格式错乱。
	% 同时还需要在电脑下载特定软件才能放映，
	另一方面，想要制作出一份视觉效果良好的幻灯片，
	不仅考验制作者的审美和对工具的熟练程度，
	而且需要花费较多的精力在排版布局、样式调整等方面。
	
	随着互联网技术的发展，基于Web的幻灯片工具逐渐出现，
	用户可以通过浏览器访问URL即可在平板、手机等多端上查看最新版本的幻灯片，
	让幻灯片的分享变得更加方便，
	同时可以结合Web实现丰富的交互式效果。
	2006年，Raggett提出了基于JavaScript和CSS的Web幻灯片框架Slidy\cite{raggett2006slidywebppt}，
	而后，Reveal.js、Marp等框架也慢慢受到用户的关注，
	不过相对于Slidev，Reveal.js和Slidy无法像Slidev一样利用Vue很方便地实现组件复用，
	且语法更加复杂。
	而Marp提供的功能相对Slidev较少，且无法方便地实现交互效果。
	

	同时，国内也有一些学者在积极探索利用Web技术制作幻灯片，
	江辰开发了一个JavaScript库，也像Slidy那样可以使用CSS和JavaScript来制作Web幻灯片\cite{JSJY2012S2039}，
	胡其美在其课件制作系统中选择Reveal.js将Markdown文档渲染为幻灯片\cite{1020353599.nh}。
	杜凡凡在其课件制作系统中，将课件存储为JSON格式，
	并利用HTML的Canvas将其渲染为幻灯片\cite{1019253093.nh}。
	类似的，曾柏羲也选择将已有的幻灯片文件解析成JSON格式的数据，
	重新将幻灯片内容渲染至浏览器，
	而且利用WebSocket实现幻灯片多端同步播放\cite{1018807854.nh}。
	在实际教学中，胡仕云发现基于H5P（HTML5 Package）的交互式习题微课可以更好地满足学习者在课堂互动和个性化学习反馈等方面的需求\cite{1023445262.nh}，
	这也看出了基于Web技术的幻灯片工具在教学方面的潜力。
	
	
	% 国内学者唐毅明\cite{1015316917.nh.iosppt}
	% 也设计了一种基于基于iOS的交互式幻灯系统。

	
	Markdown作为一种轻量级标记语言，因其简洁性和易读性在文档编写中广泛应用，并且能够支持代码高亮。
	% 曹天泽认为利用Markdown的格式与文本分离和支持语法高亮的特点，可以替代PowerPoint在程序类教学中的角色\cite{HLKX202002056}。
	曹天泽认为基于以上特点，非常适合将Markdown应用在程序类的教学中\cite{HLKX202002056}。
	一些文档管理平台也支持用户通过Markdown编写幻灯片，
	以语雀为例，它是由蚂蚁集团开发的云端知识库，支持Markdown、画板等类型的文档，
	可以方便地帮助用户管理自己的文档，且支持“演示模式”，
	允许用户以“---”的分页符，将Markdown渲染出的文档拆分为多个幻灯片页面，
	但是由于该平台主要功能是文档管理，
	无法像Slidev那样支持一些复杂的交互式演示以及动画效果，
	而交互式演示有时可以更好地传递信息和帮助用户聚焦注意力。
	不过其对于文档管理的设计理念为本平台的幻灯片管理方式提供了思路。

	LaTex Beamer是由Till Tantau于2003年为其博士答辩开发的一种LaTex特殊文档类，
	默认生成PDF文件用于演示\cite{tantau2004user}，
	主要在数学、计算机等学术领域使用，
	一些在线LaTex编辑平台如Overleaf、Texpage可以支持用户在线创作LaTex Beamer，
	在某种程度上，也算是在线的幻灯片创作平台。
	但是LaTex Beamer相对Slidev而言，同样难以方便地实现交互演示的功能。

	综上所述，
	基于Web的幻灯片工具为幻灯片制作提供了一种新的方式，
	可以制作出具有交互演示功能的幻灯片，在教学等方面具有一定的潜力，
	且具有跨平台的性质，方便幻灯片的分享和查看。
	国内外都有学者开发基于Web的幻灯片框架，或是基于这些框架和技术开发幻灯片制作平台，
	为本平台的开发提供许多思路和启发。
	其中，Slidev不仅可以支持组件复用，
	而且支持丰富的插件和主题，
	可以很轻松地制作出精美的、具有交互效果的幻灯片。
	所以，作者希望通过解决在\ref{sec:background}节中所说的一些问题，
	可以帮助用户更好地利用Slidev更高效、方便地制作幻灯片。
